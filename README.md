# Bratwurst Engine
A lightweight chess engine written in modern C++23.

## Overview
Bratwurst Engine is a cross-platform C++23 project intended to serve as a foundation for a simple and efficient chess engine.  
This repository is currently a starting point and will evolve as features are implemented.



## Building
To build the project, use CMake:

```bash
git clone https://github.com/ConstantinTopcu/BratwurstEngine.git
cd BratwurstEngine && mkdir build && cd build
cmake .. && cmake --build .
```

## Install
```bash
./UCI
```
